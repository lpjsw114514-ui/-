# 🍅 番茄钟 · 专注统计

一个简洁优雅的番茄工作法 Web 应用，支持计时、统计、等级系统和个性化设置。

**在线体验：** [https://fqz-9zs.pages.dev/](https://fqz-9zs.pages.dev/)

---

## ✨ 功能特性

- ⏱️ **番茄计时**：默认 25 分钟工作 + 5 分钟休息，支持自定义时长
- 🎯 **预设快速选择**：1分钟、5分钟、10分钟、20分钟、25分钟、30分钟、1小时、75分钟、90分钟
- 🔄 **自动循环**：工作结束后自动进入休息，休息结束后自动开始下一轮
- 📊 **专注统计**：累计专注分钟数、获得的番茄数量
- 🏆 **等级系统**：根据番茄数量自动升级（LV0 ~ LV6）
- 📝 **历史记录**：自动保存每一次专注记录
- 🎵 **音效提示**：计时结束时播放提示音
- 🎉 **完成庆祝**：每完成一个番茄显示鼓励动画
- 🌓 **昵称设置**：自定义显示昵称

## 💾 数据存储

所有数据均保存在浏览器 `localStorage` 中：

| Key | 说明 |
|-----|------|
| `pomodoro_nickname` | 用户昵称 |
| `pomodoro_records` | 专注历史记录 |
| `pomodoro_work_rest_settings` | 工作/休息时长设置 |
| `pomodoro_auto_cycle` | 自动循环开关 |
